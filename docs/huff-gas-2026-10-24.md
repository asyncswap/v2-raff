## Changes

- Pack eight released 32-bit radix-node IDs into each storage word. Popping changes the logical
  length; inactive lanes remain unreachable and are overwritten on reuse. Retained node records
  are fully initialized when allocated again. The allocator remains bounded by peak live nodes.
- Cache exact numerator/denominator extrema instead of order IDs. Repair stops when the stored
  ratio is unchanged. A recycled first insertion branch always propagates to its new ancestors.
  Selection follows one right-first eligibility path at that exact extremum, preserving price,
  priority-bid, and queue-age ordering without linear scans.
- Replace binary tick inversion with the v4 logarithmic method: 14 fractional log bits and an
  exact boundary check. This reduces order-admission and residual-repricing work; full-fill
  matching does not rely on this change for its measured savings.
- Avoid clearing the unused order slot and short-circuit comparison of identical ratio words.

The internal storage representation changes; no public selector or matching rule changes. The
optimized hook runtime is 21,194 bytes, below EIP-170's 24,576-byte limit. The standalone matching
benchmark also uses the packed allocator.

## Validation and reproduction

245 current Huff tests pass with no failures or skips, including all three pinned Unichain fork
tests and the live-input, payout-callback, claim, fee, and signature regressions. Historical storage-
specific fixtures under test/formal remain excluded and are not current Huff refinement proofs.
Python passes 43 tests. Regenerated Solidity/Huff comparisons pass 100 matching vectors, hash
vectors, and eight shared campaigns containing 514 operations, 128 matches, 8,109 order-state
checks, and 8,109 wallet checks. Native tick inversion passes 1,024 random-price comparisons and
1,024 tick-boundary fuzz cases, plus explicit extrema and 174 Python tick vectors. Allocator tests
exercise stale-lane reuse across 17 packed words and 1,024 randomized tree cases.

Run `forge test --no-match-path 'test/formal/**' --fuzz-seed 0x20261024` here. From uv4, run
`uv run --extra priority-model python examples/validate_three_way.py --solidity /path/to/contracts --huff /path/to/v2-raff`.
Export the 128-blocker fixtures with `EXPORT_GAS_FIXTURE=true forge test --match-test test_gas128Blockers -vv`.
Use measure_matching_receipts.py on a dedicated local Anvil, then compare_matching_receipts.py to
check complete receipt-event equality and calculate savings. The importer rejects a fixture whose
stored pool FeeVault differs from the hook's immutable vault. The export harness explicitly loads
that configuration before dumpState so cold configuration slots are retained.
